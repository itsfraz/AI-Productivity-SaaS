## 🚀 Features at a Glance

### 🤖 AI Coach — Powered by Google Gemini
> Your personal AI productivity coach, available on demand.

- 📅 **Smart Schedule Generator** — Generates a personalized daily plan based on your pending tasks and work patterns
- 💡 **Intelligent Insights** — Identifies your peak focus windows and recommends optimal work schedules
- ⚠️ **Burnout Prevention Alerts** — Detects high cognitive load before it becomes a problem

---

### ✅ Task Management — Kanban Board
> Visual task organization with real-time drag & drop.

| Feature | Description |
|---|---|
| 📌 **Kanban Columns** | `To Do` → `In Progress` → `Completed` |
| 🎯 **Priority Levels** | Low, Medium, High, Urgent with color coding |
| 🗂️ **Categories** | Organize tasks by Work, Personal, and custom labels |
| 📅 **Deadlines** | Date picker with overdue detection and alerts |
| ⚡ **Optimistic UI** | Instant updates before server confirmation |

### 🔥 Habit Tracker — Streak Engine
> Build unbreakable consistency with gamified streak mechanics.

```
🔥 7-Day Streak   →   ████████████████████ 100% 
🔥 5-Day Streak   →   ████████████████░░░░  71%
⚪ 0-Day Streak   →   ░░░░░░░░░░░░░░░░░░░░   0%
```

- 🔵 **Streak Freeze** — Duolingo-style mechanic: 1 free recovery per habit protects your streak when you miss a day
- 📅 **7-Day Heatmap** — Visual grid of past week completion history
- ⚡ **One-Tap Logging** — Mark habits complete with instant feedback
- 🔴 **Streak Recovery Engine** — Smart algorithm detects missed days and applies freeze if available

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

```bash
node --version   # v20+
npm --version    # v9+
```

You'll also need:
- A **MongoDB** database (local or [MongoDB Atlas](https://www.mongodb.com/cloud/atlas))
- A **Google Gemini API key** from [Google AI Studio](https://aistudio.google.com/)

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/itsfraz/AI-Productivity-SaaS.git
cd AI-Productivity-SaaS
```

### 2️⃣ Install Dependencies

```bash
# Install server dependencies
cd server
npm install

# Install client dependencies
cd ../client
npm install
```

### 3️⃣ Configure Environment Variables

```bash
# Inside /server, create a .env file
cd server
cp .env.example .env
```

Fill in your values (see [Environment Variables](#-environment-variables) below).

### 4️⃣ Start the Development Servers

Open **two terminal windows**:

```bash
# Terminal 1 — Backend (port 5000)
cd server
npm run dev

# Terminal 2 — Frontend (port 5173)
cd client
npm run dev
```

### 5️⃣ Open the App

```
🌐  http://localhost:5173
```

Register a new account — you'll be greeted with a **clean, empty dashboard** ready for your productive work! 🚀

## 🔐 Environment Variables

Create a `.env` file in the `/server` directory:

```env
# ─── Server ─────────────────────────────────────────
PORT=5000
NODE_ENV=development

# ─── Database ────────────────────────────────────────
MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/focusai

# ─── Authentication ──────────────────────────────────
JWT_SECRET=your_super_secret_jwt_key_here
JWT_EXPIRE=30d

# ─── AI ──────────────────────────────────────────────
GEMINI_API_KEY=your_google_gemini_api_key_here
```

> ⚠️ **Never commit your `.env` file.** It is already listed in `.gitignore`.

## ⚡ Performance Optimizations

This application has been heavily optimized for real-world production performance:

### Frontend
- 🔀 **Code Splitting** — `React.lazy()` + `Suspense` for all page routes
- 🧠 **React.memo** — Memoized `TaskCard`, `HabitCard`, `SidebarItem` to prevent re-renders
- 🪝 **useCallback / useMemo** — All event handlers and expensive computations are memoized
- ✅ **Functional State Updates** — `setTasks(prev => ...)` prevents stale closures
- 🚫 **No Layout Remount** — Removed `AnimatePresence mode="wait"` (was the #1 cause of repeated page reloads)
- 🧹 **Cleanup Flags** — All `useEffect` hooks include cancellation to prevent memory leaks
- 📦 **Pre-computed Column Maps** — `tasksByColumn` computed once with `useMemo` instead of filtering 6× per render

### Backend
- 🏎️ **User Caching** — In-memory cache for JWT auth middleware (5-min TTL) eliminates DB hit on every request
- 📄 **`.lean()` Queries** — Plain JS objects returned for read operations (5–10× faster than Mongoose docs)
- ⚛️ **Atomic DB Operations** — `findOneAndUpdate` / `findOneAndDelete` with ownership — 1 query instead of 2
- 📊 **Aggregation Pipelines** — Analytics uses MongoDB `$aggregate` (server-side counting) instead of fetching all documents into memory
- 🗜️ **Gzip Compression** — All API responses compressed (~70–80% smaller payloads)
- 🔗 **Compound Indexes** — `{ user, status, deadline }` index on Tasks for O(log n) query time
- ⚡ **Parallel Queries** — `Promise.all()` used wherever multiple independent DB queries are needed

## 🛡️ Security

| Feature | Implementation |
|---|---|
| 🍪 **HTTP-Only Cookies** | JWT stored in HttpOnly cookie — immune to XSS |
| 🔐 **Password Hashing** | bcryptjs with salt rounds = 10 |
| 🛡️ **Security Headers** | Helmet.js — sets CSP, X-Frame-Options, HSTS, etc. |
| 🚦 **Rate Limiting** | express-rate-limit on auth endpoints |
| 👤 **Ownership Checks** | All mutations verify `task.user === req.user._id` atomically |
| 🌐 **CORS** | Configured with `credentials: true` |
| ✅ **Input Validation** | Mongoose schema validators + Joi (server-side) |
